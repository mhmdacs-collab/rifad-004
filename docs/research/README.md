# Research and Historical Evidence

Last updated: 2026-08-17

Files below this directory are inputs to Rifad decisions, not binding product architecture.

- `loyverse/` documents observed product behavior and technical research used as a reference.
- `restaurant-pos/RESTAURANT_SERVICE_AND_CHANNEL_BENCHMARK_2026-08-17.md` compares current official Loyverse, Square, Lightspeed, Odoo and Toast restaurant/open-order/channel patterns and records the evidence behind Rifad's current restaurant-service discussion.
- `historical-proposals/` preserves earlier Odoo/hybrid/open-source evaluations and plans.

Useful algorithms, tests, failure cases and implementation evidence may still be extracted from these materials. Any adopted capability must go through `docs/adoption/CAPABILITY_ADOPTION_WORKFLOW.md` and receive a donor capability record when code/capability reuse is proposed.

Research evidence does not itself authorize implementation. Binding direction must be promoted into current architecture/product/UI decisions and, for executable behavior, the UI Execution Manifest.

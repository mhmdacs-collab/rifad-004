# Approved Visual Decisions

No external visual donor is currently approved.

Openfront, Toast or any other interface mentioned in research/discussion remains a candidate until a decision file is added here.

Use one Markdown file per decision:

```text
VISUAL-DECISION-###-short-name.md
```

Each file must contain the fields required by `../DESIGN_AUTHORITY.md` and must name the affected screen/flow IDs. Approval may cover a narrow pattern; it never grants blanket permission to copy a whole interface.
